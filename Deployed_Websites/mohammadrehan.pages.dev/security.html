Why does Windows SmartScreen show an "Unrecognized App" prompt?

As an independent software laboratory, our binaries are compiled directly from pure Rust source code and are not yet signed with a commercial Extended Validation (EV) hardware token, which costs $400–$500 annually. Microsoft Defender SmartScreen flags any newly compiled executable as "unrecognized" until it establishes a download reputation across thousands of machines.

How to independently verify binary authenticity before running:

You do not have to take our word for it. Open Windows PowerShell and run this one-line command against your downloaded setup file to compute its cryptographic SHA-256 digest:

Get-FileHash -Algorithm SHA256 .\RQL_DocumentShield_Master_Setup.exe

Compare the resulting hash against the official cryptographic registry table below. If the 64-character hash matches bit-for-bit, the binary is 100% authentic, tamper-free, and safe to execute.
