How Browser-Native WebCrypto Hardware Acceleration Works

The W3C Web Cryptography API (`crypto.subtle`) exposes native cryptographic algorithms directly to modern browser engines. When you drop an installer, disk image, or payload into this utility, JavaScript delegates the hashing computation directly to the underlying OS cryptographic subsystem or CPU instructions (such as Intel SHA Extensions / ARMv8 Crypto).

FIPS 180-4 Standard Compliance

The Secure Hash Standard (FIPS 180-4) specifies cryptographic hash algorithms produced by the National Institute of Standards and Technology (NIST). SHA-256 produces a 256-bit (32-byte) message digest, and SHA-512 produces a 512-bit (64-byte) digest. Because the mapping is deterministic and one-way, even altering a single bit in a 10GB ISO completely scrambles the output hash.
