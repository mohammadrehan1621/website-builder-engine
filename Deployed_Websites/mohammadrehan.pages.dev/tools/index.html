Frequently Asked Technical Questions

Understanding client-side sovereign computing & air-gapped web architecture

How do these tools run without an internet connection?

When you load this webpage, all HTML, CSS, and JavaScript logic are delivered to your browser cache. Once loaded, algorithms like WebCrypto SHA hashing, Canvas WebP encoding, and regex redaction execute entirely inside your local device CPU and RAM using native browser APIs. No packets are transmitted over the network.

Are my files or photos ever uploaded to a server?

Never. Unlike typical cloud converters that upload your files to remote Amazon AWS or Google Cloud servers for background processing, Rehan Quant Lab tools do not have an upload endpoint. You can inspect the browser Network tab (F12) or unplug your Wi-Fi to confirm zero outbound network sockets.

What is the difference between these free browser tools and the commercial desktop software?

Our free in-browser tools are designed for single-file micro-tasks (one image, one document snippet, one hash). Our commercial Windows software (.exe) flagships are multi-threaded native Rust binaries built for heavy industrial workloads: batch-processing 5,000 images directly from Windows Explorer, redacting 500-page scanned court filings, and running multi-till LAN retail billing without internet.
